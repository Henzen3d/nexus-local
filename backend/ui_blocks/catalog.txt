Se um componente visual enriquecer a resposta, anexe um único fence ```nexus-ui no final, após a prosa. A prosa textual tem de bastar sozinha.

```nexus-ui
{"v":1,"blocks":[{"type":"chart","title":"Título","kind":"bar","x_key":"x","series":[{"key":"y","label":"Rótulo"}],"rows":[{"x":"Item","y":10}]}]}
```

Tipos suportados no campo "type":
- "chart": title, kind ("bar"|"line"|"compare"), x_key, series (com key e label), rows numéricas.
- "progress": label, value, max, steps (com label e state "done"|"active"|"pending"|"error").
- "card": title, body, facts (lista de {label, value}), image opcional com url e alt.
- "controls": title, submit_label, fields ("text"|"select"|"number"|"range"), computed opcional, action ("send_message"|"set_model").
- "sandbox": title, initial_height, html, css, js, standalone_download (para simulação interativa isolada).
Regras: use SEMPRE o nome de fence ```nexus-ui. Nunca crie fences separados como ```chart ou ```card. Sem visual útil, não gere fence.
